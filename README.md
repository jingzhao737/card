# ⚫⚪ 游鲸围棋 Web Arcade (零服务器 P2P 棋牌平台)

这是一个**纯前端、点对点 (P2P)、零成本、无服务器**的高品质 Web 棋牌游戏平台，主打**围棋**，同时可选**五子棋**、**经典斗地主**与**正宗四人麻将**。

---

## 🌟 核心亮点与游戏大厅

- **0 成本 0 服务器**：采用 WebRTC (PeerJS) 技术，通信数据直接在玩家设备之间点对点传输，无需租赁后端服务器。
- **🀄 正宗四人麻将（大众推倒胡）**：
  - 136 张标准牌组（万、条、饼 + 东南西北中发白）。
  - 支持 **吃牌 (Chow)**、**碰牌 (Pong)**、**明杠 / 暗杠 / 补杠 (Kong)**、**平胡 / 七对 / 清一色 / 碰碰胡 / 混一色** 完整胡牌规则。
  - **拟真 3D 牌桌**：象牙白 3D 浮雕手牌、金光国风动作大字报（吃/碰/杠/胡）、最新弃牌红点发光指示、剩余牌墙计数器与庄家标识。
  - **奢华结算弹窗**：显示胡牌者、胡牌番型计算、四家积分变动与重开对局。
- **🎴 经典斗地主**：3 人 P2P / AI 自动补位，支持抢地主、顺子/炸弹/王炸识别与音效。
- **⚫⚪ 围棋 (主力游戏)**：9/13/19 路可选木纹棋盘，提子吃子、打劫 (KO)、禁自杀、停一手、数子法数目结算 (贴目)，悔棋 3 次与 AI 棋圣切磋，支持联机双人实时对战。
- **⚫⚪ 墨绿五子棋**：15x15 木纹盘面，支持 2-Tap 双击确认落子、悔棋与 AI 棋圣切磋。
- **📱 全端响应式**：移动端 9:14 修长立面与 PC 桌面端 1:1 大尺寸绒面桌布自适应。

```

├── index.html           # 主界面、四款游戏主桌台与弹窗 DOM

│   └── styles.css       # 绿绒桌面、3D 象牙牌面、金光特效与全局样式

│   ├── p2p.js           # PeerJS WebRTC P2P 网络同步引擎

│   ├── ui.js            # 手牌交互、倒计时与 DOM 渲染
│   └── main.js          # 大厅与游戏主控流程控制器
└── README.md            # 说明文档
```

## 🚀 如何使用与部署

### 1. 本地双击打开
解压或拉取代码后，在浏览器中直接双击打开 `index.html` 即可开始单机切磋或联机对局。

### 2. 免费线上部署（推荐 🌟）
将项目代码部署至 **Vercel** 或 **GitHub Pages**，即可生成专属 URL 链接，直接分享到微信/QQ 邀请好友一键开局！
