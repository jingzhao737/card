# 🎴 零服务器 P2P 网页斗地主 (Zero-Server Dou Dizhu)

这是一个**纯前端、点对点 (P2P)、零成本、无需租赁任何云服务器**的网页端斗地主游戏。

---

## 🌟 核心亮点

- **0 成本 0 服务器**：采用 WebRTC 技术，游戏通信数据直接在玩家设备之间点对点传输，不消耗任何中转服务器带宽或费用。
- **微信/QQ 链接一键加入**：建房后自动生成专属邀请链接与二维码。朋友点击链接自动进入房间，3 秒开局。
- **手机 & 电脑全端适配**：基于现代 CSS Grid / Flexbox 和触屏交互设计，微信内内置浏览器或手机 Chrome/Safari 均可完美运行。
- **单机练习模式**：内置智能 AI 机器人，即使没有网络或只有 1-2 人时也可补齐机器人随时打牌。
- **Web Audio 零依赖音效**：使用浏览器原生 Web Audio API 动态合成出牌、发牌、抢地主、炸弹音效，无音频资源加载失败问题。

## 🚀 如何使用与部署

### 1. 本地直接使用 (发压缩包给朋友)
- 解压文件后，直接在浏览器中**双击打开 `index.html`**。
- 一人点击“创建房间”，将生成的 **6 位房间号** 或 **邀请链接** 发给朋友。
- 另外两位朋友双击打开网页输入房间号，即可完成 P2P 联机对局！

### 2. 免费发布到线上（推荐 🌟 最无脑方便的方式）

为了让朋友用手机微信点击链接就能直接玩，你可以把这个静态网页放到免费的托管平台上（永久免费，1 分钟完成）：

#### 方式 A: 部署到 Vercel (最方便)
1. 注册/登录 [Vercel](https://vercel.com)。
2. 将 `doudizhu-p2p` 文件夹拖入 Vercel 或关联 GitHub 仓库部署。
3. 得到一个专属免费域名（如 `https://my-doudizhu.vercel.app`），发给朋友即可！

#### 方式 B: 部署到 GitHub Pages
1. 创建 GitHub 仓库，将本项目所有文件 Push 到仓库中。
2. 在仓库设置中进入 **Settings -> Pages**，将分支设置为 `main`。
3. 保存后即可获得免费访问网址！
